# Underwater Trash Detection

# Project Overview

Underwater pollution is a growing environmental concern that threatens marine ecosystems and aquatic life. This project aims to detect and identify underwater trash using Computer Vision and Deep Learning techniques. By automating the detection process, the system can assist environmental organizations and researchers in monitoring and cleaning polluted water bodies.

# Objectives

- Detect underwater waste from images and video streams.
- Classify different types of trash present underwater.
- Improve monitoring of marine pollution using AI-based solutions.
- Support environmental conservation efforts through automated detection.

# Dataset
The name of the dataset is : Underwater Object Detection Dataset
The model is trained on an underwater trash dataset containing images of various waste materials such as:

- Plastic Bottles
- Plastic Bags
- Cans
- Packaging Waste
- Other Marine Debris

> Note: Due to dataset size limitations, the dataset is not included in this repository.
